Privacy policy

Effective November 15, 2026.

Personal Backup Connector is an owner-operated utility for encrypted personal backups using Google Drive.

Google data access and use

The utility uses Google authorization to create, read, update, and delete backup repository files and their metadata. This access is used for backup creation, integrity checks, recovery, and retention management. Although the requested Drive scope permits broader account access, the configured backup workflow targets its designated repository.

Storage and protection

Backup contents are encrypted before upload. Authorization credentials are kept in access-restricted configuration and encrypted recovery material. The owner controls the encryption keys, recovery access, and backup retention.

Sharing

The utility does not sell Google user data or use it for advertising. Google Drive processes and stores the encrypted repository as the storage provider.

Revocation and deletion

The owner can revoke authorization through Google Account settings. Revocation stops future authorized access; it does not automatically delete existing backups. The owner can separately delete the backup repository from Google Drive.

This informational website

These pages contain no analytics scripts, cookies set by our code, forms, or authorization flow. GitHub Pages hosts the site and may process visitor information under the GitHub Privacy Statement.

Contact

Contact the maintainer through GitHub issues. Do not post credentials, personal files, or backup contents publicly.
